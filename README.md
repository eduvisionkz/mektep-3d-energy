# 3D мектеп: электр энергиясын үнемдеудің математикалық моделі

«Электр энергиясын үнемдеудің математикалық моделі» ғылыми жобасының практикалық өнімі — браузерде ашылатын интерактивті WebGL 3D мектеп.

Алдымен ғылыми зерттеу жүргізілді, содан кейін оның нәтижесін көрнекі көрсету үшін 3D мектеп жасалды. 3D модель зерттеудің негізі емес, зерттеуден шыққан практикалық өнім.

## Не істей алады

- Мектепті сырттан айналдыра қарау (екі қабат, ақ қасбет, көк шатыр, шыны кіреберіс, пандус, қоршау).
- Кіреберісті басып ішке кіру, фойе мен дәліз арқылы 10 аймаққа өту: 8 кабинет (5 фотоға ұқсатылған + 3 типтік модуль), акт залы, асхана мен асүй, спорт залы.
- Шамды, ноутбукті, интерактивті панельді, проектор экранын, теледидарды, терезе астындағы панельдерді, асүй жабдығын басу — оң жақта ақпарат панелі ашылады.
- 4 режим: «Қалыпты көрініс», «Энергия картасы», «LED сценарийі» (0/25/50/75/100%), «Табиғи жарық» (10/9/8/7 сағ).
- «Зерттеу нәтижелері»: формулалар, барлық кестелер, 4 интерактивті диаграмма (tooltip + кесте көрінісі).
- «Модельдік калькулятор»: шам саны, қуат, сағат, оқу күндері, LED үлесі, тариф. Тариф енгізілмесе ақша нәтижесі «—». Техника үшін параметрлік модель.
- «Нақты фотолар»: 36 фото, 13 топ, бейтарап сипаттамалар, толық экранды қарау.
- Әр жерде дерек түрі белгіленген: ● нақты мектеп дерегі, ◐ фотобақылау, ◇ модельдік параметр.

## Технология

- [Three.js](https://threejs.org) 0.169 (WebGL), OrbitControls, CSS2DRenderer
- Vite 5, таза JavaScript (фреймворксыз)
- Барлық 3D геометрия мен текстура кодпен жасалады (canvas текстуралар), сыртқы 3D файл жоқ — «missing texture» болмайды.
- API key қажет емес. Барлық asset жоба ішінде.

## Жергілікті іске қосу

Node.js 18+ керек.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # формулалардың бақылау мәндері
npm run build      # тест + dist/ бумасына жинау
npm run preview    # жиналған нұсқаны тексеру
```

Телефоннан тексеру: `npm run dev -- --host`, содан кейін телефонда компьютердің IP мекенжайын ашыңыз (бір Wi‑Fi желісінде).

## GitHub-қа жүктеу

### А нұсқа — браузер арқылы (бағдарлама орнатпай)

1. github.com → **New repository** → атауы, мысалы `mektep-3d-energy` → **Public** → **Create repository**.
2. Ашылған бетте **uploading an existing file** сілтемесін басыңыз.
3. Архивті компьютерде ашып, `mektep-3d-energy` бумасының **ІШІНДЕГІ** барлық файл мен буманы (`index.html`, `package.json`, `src`, `public`, `tests` т.б.) терезеге сүйреп апарыңыз. Буманың өзін емес, ішіндегісін — сонда `package.json` репозиторийдің түбінде тұрады.
4. Төменде **Commit changes** басыңыз.

Архивте 100-ден аз файл бар, сондықтан GitHub шектеуіне сыяды. `.gitignore` файлы жасырын болуы мүмкін — көрінбесе, онсыз да жұмыс істейді.

### Б нұсқа — git арқылы

1. github.com → **New repository** → атауы, мысалы `mektep-3d-energy` → **Create**.
2. Жоба бумасында:

```bash
git init
git add .
git commit -m "3D мектеп: энергия үнемдеу моделі"
git branch -M main
git remote add origin https://github.com/<сіздің-логин>/mektep-3d-energy.git
git push -u origin main
```

`node_modules/` және `dist/` `.gitignore` арқылы жүктелмейді.

## Vercel-ге орналастыру

1. vercel.com → GitHub арқылы кіру → **Add New… → Project**.
2. `mektep-3d-energy` репозиторийін таңдап **Import**.
3. Баптаулар өздігінен анықталады (`vercel.json` бар): Framework — Vite, Build — `npm run build`, Output — `dist`.
4. **Deploy**. 1–2 минуттан кейін `https://mektep-3d-energy.vercel.app` сияқты сілтеме дайын болады.
5. Кейінгі әр `git push` автоматты түрде жаңа нұсқаны жариялайды.

CLI арқылы: `npm i -g vercel`, содан кейін жоба бумасында `vercel --prod`.

`base: './'` болғандықтан жобаны GitHub Pages-ке немесе кез келген статикалық хостингке де `dist/` бумасын жүктеп орналастыруға болады.

## Деректерді жаңарту

Шамның нақты паспорттық қуаты, нақты жұмыс уақыты немесе ресми тариф белгілі болса, тек `src/data/schoolData.js` ішіндегі `MODEL` объектісін өзгертіңіз. Барлық кесте, диаграмма, 3D белгі мен калькулятор сол жерден есептеледі. Содан кейін `npm test` ішіндегі бақылау мәндерін жаңа мәндерге сәйкестендіріңіз.

## Браузерлер

Chrome, Edge, Firefox, Safari (соңғы нұсқалары), Android Chrome. WebGL жоқ құрылғыда 3D орнына хабарлама шығады, ал нәтижелер, калькулятор мен фотолар жұмыс істей береді. `prefers-reduced-motion` қосулы болса, анимациялар қысқарады.
